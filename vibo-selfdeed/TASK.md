## Этапы (обязательные)

- [ ] **START** — восстановить контекст из ViBo (`vibo find`), сводка «что я знаю»
- [ ] **SCAN** — найти проблемы, классифицировать 🔴🟡🟢, зафиксировать в ViBo
- [ ] **PROPOSE** — план правок (diff), показать хозяину, НЕ применять без подтверждения
- [ ] **FIX** — бэкап → применить → проверить (3 попытки, ≤10 мин на действие)
- [ ] **ITERATE** — % успеха, пул путей А/Б/В, смена пути при застое 2 круга
- [ ] **LEARN** — сохранить урок в ViBo (что сломано → как починено → грабли)
- [ ] **REPORT** — итог: найдено/исправлено/%, круги, пути, экономия

---

## Карта миссии

```
START → SCAN → PROPOSE → [FIX → проверка → ITERATE]* → LEARN → REPORT
```

**Матрица остановки (проверять каждый круг):**
| Состояние | Действие |
|---|---|
| % ≥ целевого | ✅ СТОП — миссия выполнена |
| % растёт | 🔄 крутить дальше |
| % замер 2 круга на пути X | 🔁 сменить путь (A/B/C) |
| % замер 2 круга на ВСЕХ путях | ⛔ СТОП — тупик, доложить |
| токены > лимита миссии | ⛔ СТОП — сохранить прогресс |
| лимит кругов (5) без цели | ⛔ СТОП — доклад |
| регресс | ↩️ откат → «грабли» в ViBo → смена пути |
